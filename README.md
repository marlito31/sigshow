# 🎭 SIGshow – Sistema de Informação Geográfica para o Entretenimento no DF

## 🗺️ Sobre o Projeto
O **SIGshow** é um **Sistema de Informação Geográfica (SIG)** voltado para o **ramo de entretenimento no Distrito Federal**, desenvolvido com o objetivo de mapear **locais de shows, eventos** e **pontos de venda de ingressos**.

A plataforma permite que usuários encontrem facilmente os eventos mais próximos e que empresas parceiras divulguem seus eventos com destaque. O projeto une **geotecnologia** e **empreendedorismo**, promovendo a integração entre o público e o setor de entretenimento local.

---

## 🚀 Funcionalidades Principais

- 📍 **Visualização geográfica de eventos e casas de show**  
  Exibição de locais no mapa utilizando recursos espaciais do PostGIS.  

- 🎟️ **Consulta de pontos de venda de ingressos**  
  Indicação dos locais próximos onde o usuário pode adquirir ingressos.  

- 🧑‍🤝‍🧑 **Área de membros**  
  Permite o cadastro e login de usuários com acesso a recursos personalizados.  

- 📢 **Espaço para parcerias e propaganda**  
  Eventos parceiros podem aparecer com destaque no mapa e na página inicial.  

- 🌐 **Interface web responsiva**  
  Desenvolvida em **HTML, CSS e JavaScript**, garantindo boa experiência em qualquer dispositivo.

---

## 🛠️ Tecnologias Utilizadas

### **Backend e Banco de Dados**
- 🐘 **PostgreSQL** – Banco de dados relacional.  
- 🧭 **PostGIS** – Extensão espacial do PostgreSQL para manipulação de dados geográficos.  

### **Frontend**
- 💻 **HTML5** – Estrutura das páginas.  
- 🎨 **CSS3** – Estilização e design responsivo.  
- ⚙️ **JavaScript** – Interatividade e integração com o backend.  

---


## 💡 **Objetivo Empreendedor

O **SIGshow** busca incentivar a **inovação e o empreendedorismo**, integrando:
- 🔸 Um sistema de **parcerias com produtores de eventos** para promover maior visibilidade.  
- 🔸 Uma **plataforma de propaganda georreferenciada**, que destaca eventos patrocinados.  
- 🔸 Um **módulo de membros**, para fidelização e personalização da experiência do usuário.  

---

## 🧩 **Exemplo de Uso

1. O usuário acessa o site do **SIGshow**.  
2. O mapa exibe os principais eventos do Distrito Federal.  
3. Ao clicar em um marcador, são exibidas informações do evento, local, data e pontos de venda.  
4. Usuários cadastrados recebem recomendações e promoções exclusivas.  
5. Organizadores podem anunciar seus eventos com destaque mediante parceria.
